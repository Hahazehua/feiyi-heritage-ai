# HAHA｜Heritage Artisans, Horizons Ahead

飞颐礼遇 AI 礼赠顾问是 HAHA 当前的产品原型。它面向全球礼赠市场，通过单页自然对话理解对象、场景与预算；Agent 最多追问 5 轮，每轮只问一个高价值问题，在信息足够或用户要求时立即给出最多 3 个可解释方案。用户可在同一页面选品、查看双语文化内容并生成结构化销售询盘。

当前目录共 50 件，其中 20 件正式演示商品参与推荐，30 件馆藏或文化参考不参与推荐。仓库没有已核验的真实商家、客户或交易成果，所有商业字段仍需真实商家确认。

## 评审最短路径

1. 阅读 [Agent 定义](AGENT.md)、[Skills 编排](SKILLS.md) 和 [反馈闭环](WORKFLOW.md)。
2. 按 [Demo 脚本](DEMO.md) 完成主路径、回退路径、授权选择和聚合分析演示。
3. 在 [Specs 证据矩阵](SPECS_EVIDENCE.md) 逐项核对代码、测试和人工证据。
4. 按 [评测与复现](EVALUATION.md) 安装、测试并启动应用。
5. 部署时使用 [Streamlit Cloud 指南](STREAMLIT_DEPLOYMENT.md)，浏览器证据见 [验收报告](BROWSER_ACCEPTANCE.md)。
6. 提交时复制 [平台文本](SUBMISSION_TEXT.md)、[PR 描述](PR_DESCRIPTION.md)，并逐项完成 [提交清单](SUBMISSION_CHECKLIST.md)。

## 产品边界

- 商品、价格、产能、交期和定制能力均为演示目录数据，不构成报价或履约承诺。
- 模型只辅助自然语言字段提取；商品资格、硬约束和排序由本地确定性代码控制。
- 缺少 API Key、模型失败或数据库不可用时，顾问仍可继续工作。
- 匿名选择只有在用户主动同意后才保存；默认不保存原始对话、姓名或联系方式。
- 当前不提供支付、订单、库存、物流或商家生产权限。
