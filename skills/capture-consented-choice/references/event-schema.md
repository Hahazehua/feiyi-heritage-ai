# Anonymous event contract

## Consent

`consent_granted`, `consent_version`, and `consented_at`. No write is permitted before consent.

## Session

`anonymous_session_id`, start/completion timestamps, conversation turn count, entry source, app version, consent metadata, and `data_source` (`consented_user` or `synthetic_demo`).

## Final requirement

Recipient, scene, budget type/amounts, quantity, style and symbolism tuples, customization types, Logo requirement, destination, delivery days, output language, user-provided field names, and inferred field names.

## Recommendation

Stable event ID and signature, anonymous session ID, ordered product IDs, rank positions, match scores, and timestamp.

## Selection

Stable event ID, recommendation/session IDs, selected product/rank, timestamp, final action, customization-brief flag, and optional anonymous feedback.

## Excluded data

No name, contact detail, detailed address, company name, identity document, IP, account ID, full chat text, API key, or database credential exists in these records.
