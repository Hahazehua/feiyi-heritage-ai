# Oral Story Studio／手艺人口述转剧本工作台

## 交付目标

Oral Story Studio 是 HAHA Story Studio 的前置入口。它把采访转写拆成带来源定位的
候选内容，让手艺人决定哪些内容可以进入公开剧本，再复用现有的 Guardian、人工批准、
分镜图和四平台发布流程。

```text
采访音视频 + 转写文本
          ↓
带时间戳的原话片段
          ↓
候选故事内容与高风险声明识别
          ↓
手艺人逐项编辑、确认或排除
          ↓
口述故事模板 → 60 秒剧本 → Guardian
          ↓
人工批准 → 分镜图 → 四平台发布包
```

## 当前可运行能力

- 粘贴中文或英文采访转写；
- 支持 `[00:42]` 格式的原始录音定位；
- 上传 MP3、WAV、M4A、MP4、MOV 或 WebM 作为来源附件；
- 保存转写文本和音视频的 SHA-256 指纹；
- 提取身份、学艺经历、个人记忆、制作过程、技艺难点、转折、感受和愿望；
- 将资质、官方认证和商业履约声明标记为“需要外部证据”；
- 保留原话、编辑后的公开表达、审核决定、审核人和审核时间；
- 导出口述来源与审核记录 JSON；
- 使用至少两条本人确认的口述生成 9:16、60 秒、六镜头剧本。

## 事实边界

“本人确认”表示系统可以准确报告手艺人确实这样讲述，并不代表口述已经成为独立的
历史证明。生成的口述故事模板会使用“手艺人确认”“他回忆”“他说”等归因表达。

以下内容不能仅凭口述进入剧本：

- 国家级、省级、大师、代表性传承人等资质；
- 官方认证或非遗定级；
- 保证全球配送、最低价、现货、交付承诺等商业履约信息。

首版提供的操作是排除这些声明。后续版本可以在 Heritage Passport 补充证书或公开来源，
通过独立审核后再使用。

## 音视频转写边界

当前版本不假装已经完成自动语音转写。上传的音视频只记录文件名和内容指纹，使用者仍需
粘贴转写文本。这使离线比赛 Demo 可以稳定复核，也为以后接入不同 ASR 供应商保留清晰
边界：供应商只负责产生 `transcript + timestamps`，事实提取、人工确认和 Guardian 不依赖
供应商。

脚本语言只会切换叙事模板，不会翻译手艺人的原话。生成英文母版前，应先准备并人工核对
英文转写，再把它作为独立口述来源生成和审核。

## 比赛演示路径

1. 进入手艺人端的 **Story Studio**。
2. 选择铁画作品。
3. 在 **Oral Story Studio** 上传采访录音，并粘贴真实转写。
4. 点击 **提取故事事实**。
5. 查看每条内容的原话、时间戳和风险状态。
6. 点击 **确认全部可公开口述，并排除高风险声明**，或逐条编辑审核。
7. 导出口述来源 JSON，作为可复核证据。
8. 点击 **用已确认口述生成 60 秒剧本**。
9. 展示 Guardian 审核、人工批准、六张分镜图和四平台 ZIP。

## 建议采访结构

为了让 60 秒剧本更完整，可以请手艺人依次回答：

1. 你是谁，从什么时候开始学习这门手艺？
2. 第一次真正完成一件作品是什么时候？
3. 哪一道工序最难，为什么？
4. 有没有一次想放弃或改变方向的经历？
5. 这门手艺对你意味着什么？
6. 你最希望海外观众和年轻人记住什么？

不要为了填满模板而编造答案。缺少的段落会保留为未记录的叙事连接，不会被写成事实。

输入转写到生成剧本的完整 Streamlit 路径。
